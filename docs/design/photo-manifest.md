# Photo manifest

Photos picked from the club's Google Drive (Marketing and Marketing '24–'25 folders) for the revamp. They arrive as `weap-photos.zip`, exported from Drive at web size (event photos 2000 px on the long edge, headshots 1000 px), already rotated upright.

After import they live in `public/photos/` as WebP. Event photos keep the file names below; headshots keep their camera file names until someone matches them to names.

Faces: the design guide says to ask before posting someone's face. Hamza confirmed these are cleared for the site.
